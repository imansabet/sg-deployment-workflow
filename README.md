# GitHub Actions Deployment Workflow

This project demonstrates a simple CI/CD pipeline using GitHub Actions to automatically deploy a static website to GitHub Pages.

## How it works
- Any change to `index.html` on the `main` branch triggers the workflow
- The site is automatically deployed to GitHub Pages
